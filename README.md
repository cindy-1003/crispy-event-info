## 功能介紹
### 首頁
- **近期演出資訊**
即時瀏覽最新的演出行程，包含活動時間、地點連結與購票連結。點擊任意活動可直接跳轉至詳細場次頁面查看細節。

- **歌單出現頻率**
統計近期與總場次的歌曲出現機率排行，並支援搜尋特定歌曲的出場機率。

### 詳細場次
- **完整演出場次紀錄**
詳細記錄今年的所有演出場次資訊與演出歌單。

- **場次勾選**
支援登入功能，供使用者自主勾選並記錄今年參加過的演出場次。

### 場次補充
若發現尚未登錄或資訊不齊全的活動，使用者可透過此功能填寫資料進行回報，提交給管理員審核更新。

### 隨機聆聽
提供隨機抽取歌曲功能，並附上各大音樂串流平台（Spotify、KKBOX、YouTube Music、Apple Music）的聆聽連結。

### 表單專區
有兩份關於脆樂團的大挑戰，以及網站的意見回饋表單。

### 👣 我去哪流浪
- **個人成就頁面**
登入後可設定專屬脆粉暱稱。

- **數據統計板**
根據勾選的場次，自動統計並展示個人的音樂足跡數據：
    - 累積參與場次
    - 共聽過幾首歌曲
    - 現場陪伴總小時數
    - 待解鎖歌曲數量
